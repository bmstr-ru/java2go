# Java to Go Transition Project

The goal of this project is to help Java developers make their first step into the world of Go.
The repository contains two identical applications implemented in Java and Go. The specification the
application is under the `docs` folder.

## Getting Started

To start using the project you must be familiar with the following tools:

- Java
- Gradle
- Intellij Idea

You also must install on your machine the following tools:

- JDK 21, e.g. [Amazon Corretto](https://aws.amazon.com/corretto/) or [Adoptium Temurin](https://adoptium.net/temurin/) 
- [Intellij Idea Ultimate Edition](https://www.jetbrains.com/idea/download/)
- [Go](https://go.dev/) version at least 1.23
- [Go plugin](https://plugins.jetbrains.com/plugin/9568-go) for Intellij Idea

I encourage you to walk through these materials before you start with this project. These are really lightweight, you'll
get some fun:

- [A Tour of Go](https://go.dev/tour/)
- [Go by Example](https://gobyexample.com/)

### Build and run
To build Java or Go version of the application please follow instructions in the corresponding `README.md` files under [java](java/README.md) or [go](go/README.md) folder.
